# 🤖 J.A.R.V.I.S. — PC Assistant

Персональный ассистент для управления компьютером через веб-чат с голосовым управлением.

Говори или пиши команду — Jarvis выполняет её на твоём ПК и отвечает голосом.

![Python](https://img.shields.io/badge/Python-3.10+-blue)
![Flask](https://img.shields.io/badge/Flask-SocketIO-green)

## Возможности

| Категория | Команды |
|-----------|---------|
| **Голос** | Распознавание речи + озвучка ответов (Web Speech API) |
| **Система** | Информация о ПК, CPU, RAM, диски |
| **Процессы** | Список, завершение по PID/имени |
| **Файлы** | Просмотр, чтение, запись, поиск |
| **Сеть** | Интерфейсы, IP, трафик |
| **Приложения** | Запуск любых программ |
| **Shell** | Выполнение любых shell-команд |
| **AI** | Понимание естественного языка (опционально, через Groq) |

## Быстрый старт

```bash
cd jarvis

# Создать виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate

# Установить зависимости
pip install -r requirements.txt

# Запустить
python jarvis.py
```

Открой http://localhost:5000 в Chrome.

## Голосовое управление

- Нажми кнопку **🎤 микрофона** или клавишу **Пробел** — скажи команду
- Jarvis распознает речь, выполнит команду и **ответит голосом**
- Переключатель **«Голос»** в шапке — вкл/выкл озвучку ответов
- Работает в Chrome (Web Speech API)

### Примеры голосовых команд

- "Открой Firefox"
- "Покажи процессы"
- "Какое сейчас время"
- "Системная информация"
- "Покажи файлы в домашней папке"

## AI-режим (опционально)

Для понимания запросов на естественном языке:

1. Получи бесплатный ключ на [console.groq.com](https://console.groq.com)
2. Установи переменную:
   ```bash
   export GROQ_API_KEY=your_key_here
   ```
3. Перезапусти Jarvis

Без AI-ключа работают все команды, но нужно использовать точные ключевые слова.

## Примеры текстовых команд

```
системная информация     → информация о ПК
процессы                 → топ процессов по CPU
убить firefox            → завершить процесс
файлы ~/Documents        → содержимое папки
читать /etc/hostname     → прочитать файл
найти ~ .py              → поиск Python-файлов
открой firefox           → запустить браузер
запусти ls -la           → выполнить shell-команду
сеть                     → сетевая информация
диски                    → использование дисков
помощь                   → список всех команд
```

## Безопасность

- Опасные команды (`rm -rf /`, `mkfs` и др.) заблокированы
- Shell-команды имеют таймаут 30 секунд
- Настраивается через `BLOCKED_COMMANDS` в `.env`
